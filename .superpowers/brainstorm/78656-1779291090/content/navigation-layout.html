Estrutura de navegação

Qual dessas abordagens parece mais certa para o CRM?

Sidebar com ícones (icon-only)

Barra lateral compacta só com ícones — máximo espaço para o conteúdo. Padrão do Attio, Linear, Superhuman.

Sidebar larga com labels

Sidebar com ícones + nomes das seções sempre visíveis. Padrão do Twenty, Notion, HubSpot. Mais orientadora para novos usuários.

Top bar reformulado (atual)

Manter a barra no topo mas redesenhada com fundo escuro, pill ativo, e mais personalidade. Mais familiar, menos ruptura.
